--------------------------------------------------------------------------------
1. GOAL
--------------------------------------------------------------------------------
Public firm website plus freely usable drafting tools for criminal, civil,
family, and revenue matters, plus an FBR / SECP practice guide hub.

- Lead capture (name, phone, email) before tool use and on contact form
- Live HTML petition preview + browser Print / Save as PDF
- Criminal modules also download court-style .docx
- Tax/corporate = checklists + official links only (no IRIS/eZfile login)
- Disclaimer: assistance only; filing remains advocate/user responsibility

--------------------------------------------------------------------------------
2. TECH STACK
--------------------------------------------------------------------------------
Frontend   : Next.js 15 (App Router) + React 19 + TypeScript + Tailwind CSS 4
Database   : SQLite via Prisma (leads, usage logs, referencer)
Admin      : Password-protected /admin (session cookie)
Criminal   : HTML preview + docx package → .docx
Print      : Browser Print / Save as PDF
Container  : Containerfile (Red Hat UBI Node 20) for OpenShift/Docker

Env:
  DATABASE_URL     = file:./dev.db  (or production equivalent)
  ADMIN_PASSWORD   = set in .env (default fallback waris-admin-2026 for local)

4. TOOLS (COMPLETED)
--------------------------------------------------------------------------------
4.1 Criminal Trial Referencer
    Searchable stages / sections / checklists; admin CRUD

4.2 Criminal Applications Writer (25+ modules)
    Bail 497/498, 249-A, 265-K, 22-A/B FIR direction, 516-A Superdari,
    491-552, NBW, appeals, revisions, ID parade, habeas, and more
    Live preview + Generate .docx

4.3 Civil Suit Writer (CPC / Specific Relief)
    Declaration, injunction, specific performance, possession, cancellation,
    damages, urban partition, temporary injunction O39; print canvas

4.4 Family Suit Writer (Family Courts Act)
    Khula, dower & maintenance, dowry + Annexure-B, custody, restitution,
    maintenance-only; locked templates under templates/family/

4.5 Revenue Applications Writer (Land Revenue Act 1967)
    Record correction, demarcation, ejectment, mutation, agri partition

4.6 FBR / SECP Practice Hub
    IRIS / eZfile checklists + research portal links (no passwords stored)
